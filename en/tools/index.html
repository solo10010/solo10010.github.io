Password generator

Passwords are generated in your browser with the cryptographic crypto.getRandomValues and never leave it.

Domain mail check: MX, SPF, DMARC

Records are fetched via Cloudflare's DNS-over-HTTPS — the domain only goes to their DNS resolver. Handy when investigating phishing and sender spoofing.

Encoder and JWT decoder

Base64, URL, HTML entities, hex and JWT decoding — all local. The JWT signature is not verified.

Server scripts
One-line runs
Proven Linux server diagnostic scripts I used for years in hosting support. They run without being saved to disk. Always check what third-party code does before running it as root — the “Code” link opens the source.
Diagnostics
measure.py
Real RAM and SWAP usage
Calculates PSS and SWAP PSS for every process and shows how much memory each user and application really takes. A detailed report is saved to /tmp/ram.csv.
curl -sSL https://solo10010.github.io/scripts/measure.py | sudo python3 -

Diagnostics
ps_mem.py
ps_mem — memory per process
Accurate per-process memory report that accounts for shared pages. Useful for sizing pm.max_children in PHP-FPM or web server worker limits.
Arguments: -p PID · -s · -t · -w N · -S
curl -sSL https://solo10010.github.io/scripts/ps_mem.py | sudo python3 -

topdiskconsumer.sh
What filled the disk
Reports the largest directories and files, deleted-but-still-open files and old files. Run it in any directory of the filesystem you need to check.
Arguments: --help · -l N · -t · -o · -d · -m · -u
curl -sSL https://solo10010.github.io/scripts/topdiskconsumer.sh | bash
