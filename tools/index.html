Калькулятор подсетей IPv4

Адрес с префиксом или маской: 10.0.0.37/22, 192.168.1.10 255.255.255.0.

Генератор паролей

Пароли создаются в браузере через криптографический генератор crypto.getRandomValues и никуда не передаются.

Проверка почты домена: MX, SPF, DMARC

Записи запрашиваются через DNS-over-HTTPS у Cloudflare — домен уходит только в их DNS-резолвер. Пригодится при разборе фишинга и подмены отправителя.

Кодировщик и декодер JWT

Base64, URL, HTML-сущности, hex и разбор JWT — всё локально. Подпись JWT не проверяется.

Скрипты для серверов
Запуск одной строкой
Проверенные скрипты для диагностики Linux-серверов, которые я годами использовал в поддержке хостинга. Запускаются без сохранения на диск. Перед запуском чужого кода от root всегда смотрите, что он делает — ссылка «Код» открывает исходник.
Диагностика
measure.py
Реальное потребление RAM и SWAP
Считает PSS и SWAP PSS всех процессов и показывает, сколько памяти на самом деле занимает каждый пользователь и приложение. Подробный отчёт сохраняет в /tmp/ram.csv.
curl -sSL https://solo10010.github.io/scripts/measure.py | sudo python3 -

Диагностика
ps_mem.py
ps_mem — память по процессам
Точный отчёт о памяти процессов с учётом разделяемых страниц. Удобно, чтобы рассчитать pm.max_children для PHP-FPM или лимиты воркеров веб-сервера.
Аргументы: -p PID · -s · -t · -w N · -S
curl -sSL https://solo10010.github.io/scripts/ps_mem.py | sudo python3 -
